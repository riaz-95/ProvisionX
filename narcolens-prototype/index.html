        Predicted synthetic-drug variants

        Chemical structures are withheld in this interface. Predictions are used only to extend the detection library and are validated against lab reference samples before going live.

        How M4 works

        1. Watch the trend. Seizure data, lab results and international early-warning feeds show which drug families are mutating.
        2. Predict the fingerprint. A graph neural network predicts the spectrum a new variant would produce, from its family's known chemistry.
        3. Validate. Forensic chemists approve each prediction against reference samples.
        4. Push to M3. Every hyperspectral camera in the network can now recognise the variant – before its first seizure.

        Federated network

        The loop

        1. Officer confirms the seizure in the case
        2. Forensic lab confirms the substance (legal proof)
        3. Each site trains on its own confirmed cases – images never leave the site
        4. Only encrypted model updates go to the NarcoLens core
        5. New model version is pushed to every scanner and desk
